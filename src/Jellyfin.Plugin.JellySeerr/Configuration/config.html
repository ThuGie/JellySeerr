JellySeerr

Discover and request movies and TV shows through Seerr, with the quality profiles you choose to offer.

Internal URL Jellyfin uses to reach Seerr, for example http://seerr:5055
Used for “Open in Seerr” links in the browser.

Sync quality profiles from Seerr, then enable only the ones users should see. Disabled profiles cannot be requested.

If off, users without Seerr Advanced Requests still get your default profile.

Asset URLs are relative (`../JellySeerr/...`) so reverse proxies and Jellyfin base URLs keep working.
